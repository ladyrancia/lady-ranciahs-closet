# Lady Ranciah's Closet 👗

A responsive fashion website designed and developed for **Lady Ranciah's Closet**, a feminine fashion brand focused on effortless, versatile and confident styles.

🌐 **Live Website:** https://ladyrancia.github.io/lady-ranciahs-closet/

---

## ✨ About the Project

Lady Ranciah's Closet is a fashion brand website created to showcase the brand's identity, collections and social platforms while providing customers with an easy way to get in touch.

The website was designed with a soft, feminine aesthetic while keeping the layout clean, responsive and user-friendly across desktop and mobile devices.

---

## 🛍️ Features

- Responsive design for desktop and mobile
- Fashion-focused landing page
- Hero section with brand imagery
- Featured collection section
- About the brand section
- Shop page
- Instagram and TikTok links
- Direct WhatsApp customer contact
- Mobile navigation menu
- Responsive mobile hamburger menu
- GitHub Pages deployment

---

## 🎨 Design

The website uses a soft, feminine visual identity designed to reflect the Lady Ranciah's Closet brand.

### Color Palette

- Blush pink
- White
- Neutral tones
- Soft muted accents

### Typography

The website uses elegant serif typography for headings to create a sophisticated fashion-brand feel, combined with clean, readable text for body content.

### Responsive Design

The website is fully responsive and adapts to:

- 💻 Desktop screens
- 📱 Mobile phones
- 📲 Tablet-sized screens

The navigation also includes a mobile hamburger menu for smaller screens.
